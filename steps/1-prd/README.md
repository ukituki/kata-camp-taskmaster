# Step 1: Vision → Plan - Create PRD

## Objective
Transform your project vision into a comprehensive Product Requirements Document (PRD) that will be parsed into actionable tasks.

## Quick Start

1. **Fill out your vision:**
   - Open `vision.md` in this folder
   - Write your project idea (what you're building, why, who it's for)
   - See `vision-template.md` for an example

2. **Generate PRD from vision:**
   - Ask your AI assistant (Cursor chat, Claude, etc.):
   - "Based on the vision in `vision.md`, create a comprehensive PRD following the template in `PRD-template.md`"
   - Or use the prompt in `PRD-generation-prompt.md`

3. **Save your PRD:**
   - Save the generated PRD as `my-prd.md` in this directory

## Files in This Step

- `vision.md` - **Fill this out** with your project idea
- `vision-template.md` - Example vision (reference only)
- `PRD-template.md` - PRD structure template
- `PRD-generation-prompt.md` - Optional AI prompt for PRD generation
