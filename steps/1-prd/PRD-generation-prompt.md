# PRD Generation Prompt

Use this prompt with your AI assistant to generate a PRD from your vision.

## Prompt

```
Based on the project vision in vision.md, create a comprehensive Product Requirements Document (PRD) following the structure in PRD-template.md.

The PRD should include all sections from the template:
1. Project Overview (problem statement, target users, value proposition)
2. Goals and Objectives (with success metrics)
3. User Stories (5-10 stories)
4. Features and Requirements (detailed for each feature)
5. Technical Requirements
6. Design Considerations
7. Success Criteria
8. Risks and Mitigations
9. Timeline and Milestones (optional)
10. Future Enhancements (optional)

Make it detailed enough to generate actionable development tasks, but scoped for a 1-2 week solo project.
```

## How to Use

1. Fill out `vision.md` with your project idea
2. Copy the prompt above
3. Paste it into your AI assistant (Cursor, Claude, ChatGPT, etc.)
4. The AI will reference `vision.md` and `PRD-template.md` to generate your PRD
5. Review and save as `my-prd.md`
