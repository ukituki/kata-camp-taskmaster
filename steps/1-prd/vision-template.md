# Project Vision (Example)

This is an example vision document. Copy this structure to `vision.md` and fill it out with your own project idea.

## What are you building?

[Describe your project idea in 2-3 sentences. What problem does it solve? Who is it for?]

Example:
"I want to build a web app that helps developers discover and test public APIs. Users can browse a curated list of APIs, test endpoints directly in the browser, and save their favorites."

## Why are you building it?

[What's the motivation? What problem are you solving?]

Example:
"Developers often waste time searching for APIs and testing them in separate tools. This app brings everything together in one place."

## Who is it for?

[Who are your target users?]

Example:
"Developers, students learning APIs, and anyone who wants to quickly test public APIs without setting up Postman or curl."

## Key Features (High Level)

[List 3-5 main features you want]

Example:
- Browse curated list of public APIs
- Test API endpoints in the browser
- View formatted JSON responses
- Save favorite APIs
- Filter and search APIs

## Technical Preferences (Optional)

[Any specific technologies you want to use?]

Example:
- React with TypeScript
- Tailwind CSS for styling
- No backend needed (client-side only)
