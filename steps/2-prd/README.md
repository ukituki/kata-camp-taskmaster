# Step 2: Vision → Plan - Create PRD

## Objective
Create a Product Requirements Document (PRD) that will be parsed into tasks.

## Tasks

1. **Review the PRD template:**
   - Open `PRD-template.md` in this folder
   - Understand the structure and sections

2. **Create your PRD:**
   - Copy the template: `cp PRD-template.md my-prd.md`
   - Edit `my-prd.md` with your project vision
   - Keep it simple for the kata session

3. **PRD should include:**
   - Project name and description
   - Goals and objectives
   - Key features (3-5 features)
   - Basic requirements
   - Success criteria

## Example PRD Topics

For the kata session, you could create a PRD for:
- A simple todo app
- A calculator
- A blog post generator
- A weather dashboard
- Or any small project you're interested in

## Success Criteria

- [ ] PRD file created (`my-prd.md`)
- [ ] PRD includes project vision
- [ ] PRD includes key features
- [ ] PRD is saved in `steps/2-prd/` folder

## Next Step

Once your PRD is ready, proceed to [Step 3: Parse PRD](../3-parse-prd/README.md)
